How to use this. One wireframe per page type, not per page. Build it with the real copy from 03 — never lorem ipsum, never placeholder boxes standing in for text of unknown length. Colour, fonts and imagery are out of bounds at this gate. Say so explicitly when you send it, and send three to five specific questions with it, or you will get feedback about the shade of blue instead of about the structure. House rules that apply now: a visible on-page fidelity tag reading LOW-FI, a real mobile layout at mobile width (not a squashed desktop one), and the hero occupying roughly the first two thirds of the viewport.

5. Responsive behaviour

Block 390px 768px 1024px+ Reflow note

Mobile check — the mobile layout follows the bizee.com reference for type size, spacing and alignment. Headings and intros centred; body copy and cards left-aligned.

  • Mobile is a genuine layout, not a narrowed desktop
  • Tap targets ≥ 44px
  • No horizontal scrolling at 390px
  • Longest German string tested in every constrained element
