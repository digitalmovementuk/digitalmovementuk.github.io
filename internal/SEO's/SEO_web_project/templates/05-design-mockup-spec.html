How to use this. Edit the wireframe forward — do not rebuild from scratch. It is the same file moving up a fidelity stage, so nothing approved at Gate 1 quietly changes. Design one page type fully, not all of them partly. Take the most important page type to a finished state, agree it, and the rest become variations rather than new designs. Pixel spacing and wordsmithing are out of bounds at this gate. Those belong to the build. Standard: low-cognitive-load-design. Strip the decoration, keep the conventions — prototypicality beats novelty. A page that looks like what it is outperforms a page that looks original.
