A 40-page brand book nobody opens is worse than two pages people follow.

Definition of Done

  • Every colour has a token name and a role
  • Contrast pairs measured, not assumed
  • Fonts licensed for web and self-hosted
  • Type scale defined for desktop and mobile
  • Tone of voice has a concrete word list, not adjectives
  • Imagery policy names what is not allowed
  • Client approved
  • Tokens transferred into F2 and the shared stylesheet
