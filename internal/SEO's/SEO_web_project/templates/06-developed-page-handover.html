How to use this. The Developer fills this in and hands it to QA. QA does not start without it. It exists so that testing is against a stated intent, not against a guess. Build order: shared stylesheet token skeleton → one template built end to end → pilot page finished completely → remaining pages populated. Components get promoted to the shared stylesheet on their second use, not their third, and never before. Never silently fix copy or change structure. If something in 03 or 05 is wrong, raise it — a fix nobody knows about is a defect QA cannot catch.

8. Accessibility implementation

  • One <h1>, heading order unbroken
  • Landmarks: header, nav, main, footer
  • Skip-to-content link
  • All images have alt text; decorative ones alt=""
  • Form labels bound to inputs
  • Errors announced, not colour-only
  • Visible focus on every interactive element
  • Fully keyboard operable
  • lang attribute set
  • prefers-reduced-motion respected
