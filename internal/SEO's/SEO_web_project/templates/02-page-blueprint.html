Its whole value is that it cannot look finished, so it cannot be signed off prematurely the way a wireframe can.

Definition of Done

  • Page purpose is a single sentence naming one action
  • Page-type inventory complete — wireframe count is now known
  • Priority guide has real content, no lorem, no layout
  • Every section justified against the page purpose
  • Deliberate omissions listed
  • User journey covers arrive → orient → evaluate → decide → act
  • Content map names an owner and a date for every "create" and "missing" row
  • Content blockers flagged to the client in writing
  • CTA strategy names the consent requirement
  • Client signed off — Gate 0 closed
